Authentication & Role-Based Access Control (RBAC)Super Admin Platform Access: Verify that a user with the Super Admin role can successfully create new tenants and assign Tenant Admins, while Tenant Admins and Users receive a 403 Forbidden when attempting the same action.   Tenant Admin Scope Restriction: Verify that a Tenant Admin can only create courses and users within their explicitly assigned tenant_id.   Super Viewer Read-Only Enforcement: Ensure that a Super Viewer can query global tenant data (returning 200 OK) but receives an unauthorized error when attempting any POST, PUT, or DELETE operations.   

2. Tenant Isolation & Data SecurityCross-Tenant ID Guessing (Horizontal Privilege Escalation): Authenticate as a Tenant A User and make an API request using the ID of a course belonging to Tenant B; verify the system rejects the request.   Admin Cross-Tenant Mutation Prevention: Authenticate as a Tenant A Admin and attempt to modify a user account belonging to Tenant B; assert that the operation fails and does not alter Tenant B's data.   Missing Tenant Context Rejection: Attempt to create a course or assign a user without providing a valid tenant_id context in the request payload; ensure the backend catches the missing boundary and rejects the payload.

3. Tenant Expiration & Lifecycle ManagementExpired Tenant Lockout: Programmatically set a tenant's status to "Expired" and simulate a Tenant User login attempt; verify that the API restricts access to all learning functionalities.   Idempotent Expiration Processing: Trigger the background expiration job multiple times on an already-expired tenant; ensure the system handles repeated processing gracefully without duplicating database updates.   Trial Reactivation Data Integrity: Transition an expired tenant back to an active state and verify that all previously assigned courses and user progress metrics are fully restored and accessible.   

4. Course Assignment & Learning ProgressSuccessful Course Assignment: Authenticate as a Tenant Admin, assign a course to a valid Tenant User within the same tenant, and verify the association appears in the database.   Progress Tracking State Updates: Simulate a Tenant User completing a lesson; verify that their individual completion percentage updates correctly and the Tenant Admin can view this updated progress.   Unauthorized Assignment Prevention: Verify that a Tenant User cannot assign a course to themselves or artificially inflate their own progress metrics through unauthorized API mutations.
